# AI 整本超分后台计划运行（进度 + 完成提示 + 阅读界面版本切换）

## Goal

整本 AI 超分改为后台计划任务：用户确认后立即后台运行，不阻塞其他操作；角落显示进度；完成时若正在阅读该漫画则提示切换；阅读界面内可直接选择原版/超分版本（替代原先只在详情页的入口）。取代 backlog `08-01-m2-backlog` 中 #7（后台计划超分）。

## Requirements

- **R1** 选择整本超分时询问（现有确认对话框基础上），确认后任务立即进入后台队列。
- **R2** 后台运行：任务期间用户可自由操作（翻页、浏览其他书）；角落常驻进度浮层（如"AI 超分中 3/120"），可查看/取消。
- **R3** 完成提示：任务完成时若用户**正在阅读该漫画**，弹出"该漫画已超分完毕，是否全部加载为超分版本？"；否则仅角落/通知提示完成。
- **R4** 阅读界面版本切换：阅读器中可直接切换"原版 / 超分版本"（当前仅详情页有 `openBookNoAi` 入口），切换即时生效且不丢失阅读位置。
- **R5** 队列管理：多任务排队；同一本书不重复入队；支持取消。
- **R6** 性能：后台任务复用 `superResolveBatch()` 的分块批量模式（20 页/批，内存有界、CLI 启动次数少），并把 `book_detail_page._upscaleAll` 的现有批量逻辑抽成共享服务。
- **R7（已定：O1-B 持久队列）**：任务队列持久化到 SQLite（新增 `ai_tasks` 表），启动时自动加载并**续跑** queued/running 任务；已完成的页走缓存命中快速跳过。

## Acceptance Criteria

- [ ] 整本超分确认后立即后台执行，UI 不卡顿
- [ ] 角落进度实时更新，取消后任务中止且缓存一致
- [ ] 完成时正在阅读该书 → 弹出切换提示；不在阅读 → 不打断
- [ ] 阅读界面原版/超分切换即时生效、阅读进度保留
- [ ] 同一本书重复触发不产生重复任务
- [ ] 重启应用后未完成任务自动续跑（已完成页秒过）
- [ ] 取消任务后已完成页缓存保留，重新触发可续
