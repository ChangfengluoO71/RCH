# 全局设置自定义漫画详情页信息显示

## Goal

全局设置中可配置漫画详情页展示哪些信息字段（如不显示作者、类别、感想、已读页数等），让界面按用户偏好精简。

## Requirements

- **R1** 全局设置新增"详情页信息显示"配置，按字段开关：作者、类别、系列、感想/简介、评论、已读页数（页数显示见 `detail-page-stats`）、标签等。
- **R2** 详情页按开关渲染对应字段；全部关闭时显示基础信息（标题/封面/操作按钮）。
- **R3** 配置持久化（settings），重启保持。

## Acceptance Criteria

- [ ] 每个字段独立开关且立即生效
- [ ] 全部关闭不报错、布局正常
- [ ] 配置持久化
- [ ] `flutter analyze` 0 issues

## Open Questions（开工前确认）

- **O1** 可开关字段清单（默认全开）：作者 / 类别 / 系列 / 感想 / 评论 / 已读页数 / 标签 / 更多？
- **O2** 开关 UI 形式：设置页 SwitchListTile 列表（推荐）。
