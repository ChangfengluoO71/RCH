# 漫画详情页显示页数与已读页数

## Goal

漫画详情页展示该漫画的总页数与当前已读页数（阅读进度），帮助用户快速判断阅读位置。

## Requirements

- **R1** 详情页显示"共 N 页"（本地/WebDAV 书的总页数）。
- **R2** 详情页显示"已读至第 M 页"（来自阅读记录的 `lastPage`；未读过显示"未开始"）。
- **R3** 数据来源：总页数需打开书籍句柄获取（`openLocalBook`/`openWebdavBook` → `pageCount`）；已读页数直接读记录。打开句柄应即开即关，避免句柄泄漏。

## Acceptance Criteria

- [ ] 本地书与 WebDAV 书详情页均显示总页数
- [ ] 已读页数随阅读进度更新；未读显示"未开始"
- [ ] 打开句柄正确释放（无泄漏）
- [ ] 详情页打开不因取页数明显变慢（异步加载）
- [ ] `flutter analyze` 0 issues

## Open Questions（开工前确认）

- **O1** 页数获取开销：WebDAV 书打开句柄可能触发网络/解压，是否做缓存（记录页数到 meta）？推荐：meta 缓存 + 后台刷新。
- **O2** 显示样式：并入现有信息行 vs 独立行。
