# 首次启动缓存目录设置引导

## Goal

用户第一次打开应用时进行缓存目录设置引导，避免后续手动迁移的痛点（衔接 `cache-dir-migration`）。

## Requirements

- **R1** 首次启动（判定：无已持久化的缓存目录设置且无/极少用户数据）弹出引导页：推荐默认缓存目录（含预期占用说明）或自定义目录。
- **R2** 选择自定义 → 走 `cache-dir-migration` 的目录选择 + 迁移流程（首次即空目录，迁移内容为空）。
- **R3** 可跳过（用默认），不再重复打扰；引导完成后正常进入主页。

## Acceptance Criteria

- [ ] 首次启动出现引导，选择后不再出现
- [ ] 自定义路径选择与校验可用（空目录可创建）
- [ ] 跳过/默认路径直接进入主页
- [ ] `flutter analyze` 0 issues

## Open Questions（开工前确认）

- **O1** 引导触发条件：仅"从未设置过 cacheDir"即可，还是需要额外"数据为空"判定？推荐仅从未设置过。
- **O2** 引导页形式：全屏向导页 vs 首页弹窗，推荐全屏向导。
