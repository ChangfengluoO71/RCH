# P2 备份即同步（WebDAV + 同步盘目录双通道）

## Goal

标准包经两种用户自有通道双向传输：模式 A 主动 WebDAV；模式 B 网盘同步盘目录。手动/定时触发，失败可观测可重试。

## Requirements

- R1 模式 A：复用 WebDAV 会话基建，push / pull / 恢复标准包，手动 + 定时
- R2 模式 B：设置"同步目录"；应用原子写包（临时文件 + rename）；启动/定时/文件变化扫描远端包
- R3 冲突副本识别：网盘客户端 `xxx (冲突副本)` / `xxx(1)` 命名识别与忽略/择优
- R4 恢复流程：选择标准包 → 校验 → 导入合并（合并引擎 P3 提供前先做全量替换导入）
- R5 UI：设置页"备份/同步"分组，含模式选择、同步目录、最近同步状态

## Acceptance Criteria

- [ ] 两模式上传/下载/恢复全链路可用
- [ ] 失败可观测、可重试；冲突副本不导致数据损坏
- [ ] 恢复后数据与包一致
