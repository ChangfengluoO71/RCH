# 115 Cookie 过期自动续期 + 更新下载镜像

## 需求

1. **115 扫码 Cookie 模式自动续期（方案 A）**：
   - Cookie 失效（登录状态已失效 / Cookie 过期 / 重新扫码提示）时，自动弹出扫码对话框；
   - 扫码成功后自动替换书源 Cookie、清理会话缓存并重试原操作（浏览 / 打开 / 封面）；
   - 用户取消扫码时保留原错误提示；同一书源并发请求只弹一次扫码框；
   - 编辑书源对话框为 Cookie 模式增加「重新扫码」按钮。
2. **GitHub 下载镜像**：
   - 设置 → 关于与更新 增加「下载通道（镜像）」选项：官方 GitHub / ghproxy.net / gh-proxy.com / ghfast.top / mirror.ghproxy.com / 自定义；
   - 镜像只作用于安装包下载 URL（前缀代理），版本检查仍走官方 API；
   - 选择持久化到 AppSettings，重启不丢。

## 验收标准

- 115 Cookie 模式任一操作触发「登录状态已失效」类错误时弹出扫码框；扫码成功后自动替换 Cookie 并重试成功；
- 编辑书源可一键重新扫码；
- 镜像设置持久化，下载使用 `镜像前缀 + 官方直链`，失败时错误信息提示检查镜像；
- `flutter analyze` 无问题；`flutter test` 全绿。
