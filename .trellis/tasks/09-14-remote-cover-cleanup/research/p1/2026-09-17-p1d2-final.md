# 3. 实现（local A + legacy B）

## local A

删除 `_maybeLoad` 顶层 `if (widget.remoteAssetId == null && _remoteCoverNetworkPaused) return;`，
改为**按能力**判断：

* **需要 session 的 legacy 源**（kind ≠ null）→ `_load` 内先 local-only 查找；miss 且 offline →
  **直接** `throw const _RemoteCoverFetchDisabled()`（**不**进入 session helper 去换一个异常）。
* **纯本地源**（kind == null，最终走 `bookCover`）→ 完全不经过 local-only 查找与 offline 停止，
  直接执行（本地文件 + Rust decode，零 session、零网络）。
* **unified** → 未改动（`_loadUnifiedRemoteCover` 内部先读本地，`remote_cover_read` 本身不触网）。

## legacy B（顺序不变量）

```
legacy
  ↓  readLegacyCoverLocal(...)        ← 纯本地；sessionless；不受网络开关影响
  ├─ HIT  → display → return
  └─ MISS
       ├─ offline → throw _RemoteCoverFetchDisabled → 既有 placeholder
       └─ online  → _loadLegacyRemoteCover（**既有** session getter → 既有 provider fetch）
```

local lookup 由插入位置保证**严格早于** transport（即早于 `_guardRemoteCoverIo` 与 session getter）。

## SFTP：薄包装共享 parser

`lib/store/sftp_session.dart` 新增 `(String, int) sftpHostPortOf(BookSource source) => _parseHostPort(source);`
—— 内部只调用既有 `_parseHostPort`，**未复制解析逻辑、未新增 normalization、未改其行为**。
链条：**same Dart parser → Rust `endpoint_for` → same cache identity**。reader 内无任何 `if port == 22`。

## DTO mapping（Dart 只填 logical fields）

`kind / url / host / port / appKey / appId / rootId / root / logicalPath / page / width / height / crop`。
Dart **不构造** origin / endpoint / raw cache path / `.cover` path / hash。
`root` 按 kind 取值：`baidu → source.path`；`115web|quark → source.rootId`；其余 `''`。

## Family 2 零特判

115-web / Quark 的 raw 存在时以 raw-key 写入、raw 删除后属**已冻结的 known unrecoverable historical case**：
Rust 返回 `None`，Dart 只当普通 MISS（offline → placeholder；online → 正常进入原 provider path）。
**无** filename 查询、无缓存目录扫描、无 orphan 检测、无 background repair、无特殊错误 UI。
