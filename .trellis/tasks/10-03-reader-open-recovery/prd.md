# 阅读器打开与失败恢复

## 目标

让用户能看见远程连接、书本打开和首屏加载状态；失败可恢复，退出等待后不会发生晚到状态写入或资源泄漏。

## 需求

- 进入阅读器后立即显示阶段：连接书源、打开漫画/下载、加载首屏、阅读就绪。
- 保留现有下载百分比；连接失败或书本打开失败时显示原因和重新打开入口。
- 用户可退出当前等待页；已开始的阻塞式远程操作可能继续到本次调用结束，晚到结果必须被忽略并关闭书本句柄。
- 页面自动加载失败有有限重试与退避；最终失败显示重试按钮，不得被重建触发无限请求。
- PhotoView 控制器在关联页面卸载后释放，并保留当前页面及相邻页面所需的控制器。
- 诊断日志分别记录连接、书本打开、流式尝试、回退下载、整体打开和首屏耗时，不写入凭据或完整路径。
- 远程资料库的逻辑路径与 provider 文件标识必须分开；索引/阅读记录继续使用逻辑路径，远程文件接口使用当前扫描路由中的 provider 文件标识。
- ReaderPage 卸载时清理 AI 当前阅读状态不得在 Flutter widget tree 锁定期间同步通知监听器，也不得清掉随后打开的新阅读页状态。

## 验收标准

- 从点击打开到首屏可见期间，加载状态有明确阶段和已有的下载进度。
- 打开失败可原地重试；退出后晚到结果不调用已卸载 widget 的 `setState`，也不留下 Rust book handle。
- 页读取最多自动尝试 3 次；失败后显示可点击的单页重试入口，重建不会自动清零重试状态。
- 翻页/跳页过程中，PhotoView 控制器只在相应子树卸载后释放。
- Quark 流式失败回退日志中 `stream_ms` 是失败尝试时间，`download_ms` 是下载时间，`total_ms` 覆盖实际打开工作；首屏耗时在 Dart 阅览器层单独记录。
- 以远程索引路径启动随机阅读、阅读历史、封面编辑和 AI 处理时，Quark、百度、115 API 收到 provider 文件标识；浏览器直接传入 provider 标识的旧路径继续有效。
- 失败阅读页退出后不产生 `widget tree was locked` 状态通知；快速打开另一页时，旧页清理不能清除新页的 AI 阅读状态。

## 补充需求：跳转与分页加载体验

- 阅读器“随机阅读一本”图标与主界面的骰子图标一致。
- 流式阅读跳转后，目标页优先取得 Rust 与远程网络请求许可；窗口外的旧预取失败不反复重试，也不让当前可见页的加载指示器一直转动。
- 双页模式只把当前可见跨页作为前台加载；条漫先加载显式目标，之后再低优先级加载附近页面。用户翻到正在排队的预取页时，前台请求可越过仍排队的预取任务。
- 页面原图到达后立即显示；AI 缓存命中作为后续增强应用，不能延迟原图首显。
- `reader_diag.log` 追加安全的可见页加载耗时记录，不记录漫画路径、标题、页码或凭据。

## 补充验收标准：跳转与分页加载体验

- 随机按钮使用主界面的 `casino_outlined` 图标。
- 远距离条漫跳转期间只把目标页作为前台请求；目标页显示后邻页走预取优先级。
- 阅读器不因不可见的预取页面显示当前视图的加载旋转标记。
- 前台页面请求可以优先于仍在 Rust governor 队列中的同页预取；同页已经开始的同步 I/O 继续共享结果，不制造重复下载。
- Dart 通常最多保持 3 个页读取调用；若旧请求占满这 3 个位置，允许 1 个当前目标进入 Rust 优先级队列，Dart 总调用数最多 4。Rust 远程读取仍受现有 governor 并发上限约束。
- 远程前台页加载成功/失败后，诊断日志追加耗时事件且不含资源身份信息。

## 补充需求：条漫远距离跳页与请求背压

- 条漫跳到远处页面时，中间用于估算布局的占位项不得各自发起页面读取；只读取显式目标或当前视口附近的有限窗口。
- 页面高度估算只采集真实图片的渲染高度。未加载项的占位高度必须与跳转偏移模型使用同一估值，避免页码到滚动位置的映射漂移。
- 程序化跳转目标保持有效到首帧布局完成；用户手动滚动或新跳转会使旧目标失效。
- 远跳期间不得因 Rust 阻塞请求队列暂满而让目标页进入最终失败状态。
