# 外观设置与平台材质

## 目标

改进 RCH 外观设置的层级与预览，并补充系统亮度、Android 动态配色和 Windows 窗口材质选项。保持现有主题和字体可用，确保文字在不同配色与材质下仍清楚可读。

## 需求

- 沿用当前“外观与布局”设置入口，整理外观、显示、窗口小节；外观设置适配窄屏和桌面窗口。
- 保留现有四种配色、四种字体；配色预览和字体样例直接反映当前设置。
- 亮度支持浅色、深色、跟随系统，默认仍为深色。
- Android 12+ 可选择系统动态配色；不可用时使用保存的固定配色。
- Windows 11 22H2+ 可选择 Mica 主窗口背景和 Acrylic 对话框/模态底部面板；不支持时回退为标准材质。
- 新设置保存在现有本机 AppSettings JSON 中，不加入书籍元数据或同步记录。
- 阅读画布、漫画图像、漫画封面和阅读进度不受材质滤镜影响。

## 验收标准

- 设置页面分组清楚、行间距一致，窄屏和桌面均无裁切；预览控件可读且与主题一致。
- 亮度、配色来源、字体和材质选择保存后重启仍生效，旧设置仍默认深色和标准材质。
- Android 动态配色仅在 Android 12+ 生效；其他场景回退至已保存的 RCH 配色。
- 云母仅影响受支持 Windows 的主窗口背景；亚克力仅影响 RCH 对话框和模态底部面板。
- 高对比度模式使用标准浮层；漫画封面、漫画网格和阅读画布不会被模糊。
- 新设置不改变同步数据结构。

## 范围外

- 全面重排设置页面或其他应用页面。
- Android 上模拟或标注 Windows 云母/亚克力。
- 为下拉框、锚定菜单和系统文件选择器加入亚克力。
- 自定义颜色、壁纸背景或在线字体下载。
