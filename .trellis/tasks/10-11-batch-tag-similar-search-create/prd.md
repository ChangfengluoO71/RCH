# 批量标签相似搜索与新标签创建

## Goal

让用户在批量打标签时能复用相似的已有标签；没有合适标签时，可创建新标签并继续完成当前批量操作。

## Background

用户反馈输入不存在的标签时，批量标签操作会没有反应。

## Requirements

- 批量标签输入应搜索并显示相似的已有标签。
- 找不到合适标签时，询问用户是否创建输入的标签。
- 用户确认后创建新标签，并继续将该标签应用到当前选中的漫画。
- 用户取消时不创建或应用标签。

## Acceptance Criteria

- [x] 输入与已有标签相似的文本时，用户能找到并选择已有标签，随后成功应用到当前批量选择。
- [x] 没有合适候选时出现创建确认；确认后新标签被保存并应用到当前批量选择。
- [x] 取消创建不会保存或应用标签；所有路径均有明确反馈，不会无响应。

## Deferred Details

- 相似度匹配阈值、候选排序及多个候选的交互方式在实现规划时确定。

## Notes

- 当前批量标签入口位于 `app/lib/ui/source_browser.dart`，目标收集逻辑位于 `app/lib/ui/batch_tagging.dart`。
