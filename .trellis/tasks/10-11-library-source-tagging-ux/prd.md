# 书源添加与批量标签体验优化

## Goal

改善添加书源和批量打标签时的等待与无响应体验，让用户能看到操作进度，并能顺利使用已有或新建标签。

## Requirements

- 跟进添加书源约 8 秒的耗时问题，调查可优化的环节，并在添加期间显示等待转圈。
- 批量打标签时搜索相似的已有标签；没有合适标签时询问用户是否创建，确认后创建并继续应用到当前选中的漫画。
- 两项改进分别作为独立子任务跟踪。

## Acceptance Criteria

- [ ] 添加书源时，耗时得到测量和优化；等待期间有明确的转圈反馈。
- [ ] 批量打标签可以找到并使用相似的已有标签；无合适标签时可确认创建，并将新标签应用到当前批量选择。
- [ ] 两个子任务分别具备可验证的验收标准。

## Deferred Details

- 添加书源的目标耗时需结合真实设备测量和耗时来源确定。
- 相似标签的匹配阈值、候选展示方式和创建确认文案在对应子任务规划时确定。

## Notes

- 子任务：`10-11-source-add-latency-spinner`、`10-11-batch-tag-similar-search-create`。
- 本父任务仅负责跟踪两项体验改进及最终集成验收。
