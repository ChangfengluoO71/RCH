## ✨ 核心亮点

- 📚 **大多数漫画格式通吃** — ZIP/CBZ、EPUB、CB7、CBT、PDF、CBR/RAR、MOBI/AZW/AZW3、文件夹
- 🖼️ **本地漫画快速扫描生成海报墙** — 秒级扫描本地目录；云端书源仅对「点开阅读过」的漫画显示封面
- ✂️ **封面裁剪 + 漫画旋转缩放** — 自定义封面裁剪区域；阅读中每页独立旋转、缩放
- 📖 **日漫 / 美漫 / 条漫三种阅读模式 + 双页拼接** — 电脑与平板大屏阅读更舒适
- 🤖 **漫画超分辨率（AI 2x）** — 端侧推理放大画面；受性能限制，目前仅 Windows 电脑可用
- 🏷️ **标签系统 + 详细阅读记录** — 所看所得所想皆可记：分层标签、已读标记、阅读时间 / 次数
- 🔄 **多设备同步（0.5.0 重构）** — WebDAV + 三方合并：书源 / 元数据 / 标签 / 阅读记录 / 设置 / 离线索引跨端同步，自动拉取推送，无需手动操作
- ☁️ **百度 / 夸克 / 115 网盘直连** — 流式阅读或整本下载阅读
- 🌐 **WebDAV 书源** — 未直接支持的网盘可用 OpenList 等挂载成 WebDAV 先凑合用
- 🧹 **清晰明了的缓存管理** — 分类展示占用、一键清理，减少空间占用
- 🔍 **文字 + 标签筛选** — 关键词与标签组合过滤，精准定位漫画

## 📖 功能介绍

### 打开即读，格式通吃

- **流式解析**：ZIP/CBZ/EPUB 只读取文件尾部中央目录，按需解压单页，几百 MB 的压缩包也是即点即读
- **格式支持**：ZIP / CBZ、EPUB、文件夹（Folder）、CB7 / 7Z、CBT / TAR、PDF、CBR / RAR、MOBI / AZW / AZW3（Android 端 PDF 按需渲染、CBR/RAR 原生解码）
- **文件夹漫画**：包含图片的文件夹自动识别为漫画，自动读取 `ComicInfo.xml` / `metadata.json` 元数据（标题 / 作者 / 系列 / 类别）
- **本地书架**：浏览本地目录，漫画文件夹在海报墙直接显示封面卡片，点击进入详情页

### 流畅的阅读体验

- 三种阅读模式：**日漫**（右翻双页）、**美漫**（左翻）、**条漫**（竖向滚动）
- **双页拼接** + "首页单独显示"，双页模式下可缩放拖动
- **缩放**：`+` / `-` / `0` 键，或触控板 / 鼠标滚轮
- **页面旋转**：右键"界面旋转"或对单页旋转，每页旋转结果自动记住，下次打开不变
- **进度记忆**：重开直接跳到上次阅读位置；最近阅读 / 最多阅读自动记录
- **智能预取**：后台预读前后 3 页，翻页零等待；磁盘缓存让重复阅读秒开

### AI 2x 超分

- **单页超分**：阅读中右键当前页 → “AI 超分 (2x)”，本页立即放大（Real-ESRGAN 模型，端侧推理）
- **整本超分**：详情页一键加入后台队列，可多本排队、随时取消
- **任务列表**：悬浮窗展开可见全部任务，**拖拽调整排队顺序**，进行中任务置顶；重启后队列与顺序保持
- **版本切换**：超分完成后一键切换到超分版阅读，页码不丢失；阅读中随时切回原版

### 标签与整理

- **元数据标签分层折叠**：作者 / 类别 / 系列 / AI超分 / 状态分组展示，每组独立展开收起
- **已读标记**：打开自动标记"已读"，也可批量打标（含文件夹递归）
- **标签管理页**：统计每个标签关联的漫画数与总阅读次数，支持重命名、删除
- **漫画排序**：书源浏览支持按**字母**（数字感知）或**加入时间**（最新在前）排序
- **自动转 CBZ**：本地刷新时后台将漫画文件夹 / zip 自动打包为 CBZ（全局设置可关闭）
- **后缀别名识别**：`zip` 改名 `cbz`（或文件夹转 CBZ）后仍视为同一本书，进度、标签无缝延续

### 远程书架（WebDAV / SMB / SFTP / 网盘）

- **WebDAV**：连接支持 WebDAV 的 NAS / 网盘，PROPFIND 浏览目录，Range 流式阅读
- **SMB**：直接填 UNC 共享路径（`\\NAS\漫画`）即可浏览，无需额外配置
- **SFTP**：密码认证远程书架，支持流式读取与整本下载缓存
- **百度网盘**：直连百度官方 API，浏览器 OAuth 授权一次即可，支持根目录/子目录挂载
- **115 网盘**：两种连接方式——扫码获取 Cookie（无需申请，默认）或官方 APP ID 模式，支持根文件夹 ID 挂载
- **夸克网盘**：Cookie 认证（pan.quark.cn 登录后粘贴），fid 目录浏览，三态打开策略与封面/本地缓存
- **打开策略（全局设置）**：自动（先整本下载，失败转流式）/ 优先下载整本 / 直接流式，所有远程书源通用
- **流式阅读**：支持 Range 的服务边下边读；否则首次整本下载到本地缓存，之后秒开
- 下载进度条实时显示；封面懒加载，已下载漫画封面不走网络；token 自动刷新，重启无需重新授权
- **百度网盘 token 维护**：书源浏览页顶部钥匙按钮可手动重新连接并刷新 refresh_token；失效时自动打开授权页引导重新授权

> 📖 各网盘的详细添加步骤见下文「添加远程书源教程」。

### 数据与隐私

- 阅读记录、标签、元数据、设置存于本地 **SQLite**，并有 JSON 备份
- **缓存目录可自定义**：可在设置中迁移整个数据根目录（数据库 + 缓存一起搬），重启自动恢复
- **五级缓存管理面板**：页面缓存 / 整本下载 / 封面缩略图 / AI 超分结果 / 临时文件，分类展示占用空间，可单独清理
- 全程无账号体系，不上传任何数据

## 🔄 多设备同步（0.5.0 新增）

0.5.0 把同步彻底重写为 **WebDAV 状态文件 + 三方合并**：两台及以上设备通过同一个 WebDAV 目录
（坚果云、Nextcloud、NAS 等）自动交换数据。**同步内容**：书源、漫画元数据（标题/封面裁剪等）、
标签、阅读记录、设置、离线索引；**不同步**：漫画文件本体（漫画仍留在各自的存储上）、
书源凭据（密码/Cookie 默认不上传）。

### 快速配置

1. 任选一台设备（建议数据最全的那台）先配置并同步一次：
   **设置 → 同步**，填写：
   - **WebDAV 地址**：如坚果云 `https://dav.jianguoyun.com/dav/`；
   - **账号 / 密码**：WebDAV 账号；
   - **远程目录**：如 `RCH同步`（多台设备必须填**完全一样**的目录）；
   - **设备名称**：用于区分设备（如「主力机」「MuMu」）。
2. 点「立即同步」：首次会把本机全部可同步数据推送到远端，生成同步库。
3. 其他设备：**安装同一版本** → 填**相同的 WebDAV 地址/账号/目录** → 「立即同步」，
   会自动采纳同一个同步库并把本机数据合并进去。
4. 之后无需手动操作：启动 / 每 60 秒轻量检查 / 本机有变化时自动同步。

> 同步目录里出现 `manifest.json` 与 `state/` 即表示同步库已建立；不要手动修改这些文件。

### 离线索引

离线索引是书源目录树的本地快照（路径/文件名/大小），用于**不连服务器也能浏览目录**。

- **本地书源**：自动扫描（默认在线浏览真实目录），无需手动操作；
- **云端书源**（夸克/115/WebDAV 等）：
  - 打开书源默认**在线浏览**；
  - 浏览过的目录、阅读/缓存/打标签（含未读批量标签）过的漫画，会**自动积累**进离线索引（零网络）；
  - 点顶栏 ⚡「生成离线索引（本地快照，不联网）」可从本地浏览记录批量生成；
  - 需要一次性索引整个云端目录时，用顶栏菜单「全量重建索引（联网）」（目录很大时耗时较长）；
  - 离线浏览时点 ☁「退出离线浏览」可切回在线。
- 离线索引会**随同步传播**到其他设备：A 设备浏览/标记过的书，B 设备也能离线看到条目。

### 升级与踩坑（重要）

| 场景 | 处理 |
|---|---|
| **从 v0.4.x 及更早升级到 v0.5.0（同步）** | 同步协议重构，**旧同步状态不能直接续用**：任选一台设备执行重置脚本（Windows：[sync-repair-reset.ps1](.trellis/tasks/archive/2026-08/08-09-sync-rework/sync-repair-reset.ps1)，或 Android 清应用数据）→ **清空远端 WebDAV 同步目录** → 数据最全的设备先同步 → 其余设备再加入。漫画/书源数据不受影响，升级前建议先导出 rchpkg 备份 |
| 同步报 `HTTP 409 AncestorsNotFound` | 远程目录名带**隐藏控制字符**（从别处复制粘贴目录名导致）或目录不存在。0.5.0 已自动清理控制字符；把目录重新输入一遍并确认坚果云上该目录存在 |
| 同步报 `HTTP 503 Too many requests` | 请求过频触发服务端限流。0.5.0 已改为轻量轮询 + 失败自动退避；等待片刻会自动重试，无需操作 |
| 提示「远端状态文件为空（旧版残留）」 | 旧协议曾把未变化实体写成空文件。属**安全拦截**（不会损坏数据）：按第一行「升级与踩坑」重置同步即可 |
| 旧版同步过的书源/数据“消失” | 0.4.x 旧协议存在数据清空缺陷；升级后按重置流程重新同步可恢复（被旧协议清掉的数据需重新添加/扫描） |
| MuMu / Android 模拟器 | 必须安装 **0.5.0 新 APK** 后再开同步；旧 APK 会用旧协议写空文件污染远端（新版已安全拦截） |
| 多级目录层级错乱 / 点“上一级”退出书源 | 0.5.0 已修复（显式父目录 + 上级/返回按钮分离）；重新浏览或“生成离线索引（本地快照）”会自动修正 |
| 离线索引为空 | 云端源需先在线浏览/阅读/打标签自动积累，或点「生成离线索引（本地快照）」；本地源自动扫描 |

## 🛠️ 添加远程书源教程

### 1. 入口

打开 RCH 后，左侧栏「书源」一行的最右侧有一个 **➕** 按钮，点击打开「添加书源」对话框。

对话框顶部选择**类型**，可选：本地目录 / WebDAV / SMB / SFTP / 百度网盘 / 115 网盘 / 夸克网盘；下面填「名称（可选）」和该类型对应的字段，最后点「添加」。添加时会先做连通性测试（按钮显示「测试中…」），失败会在对话框内红字提示原因。

添加成功后，书源会出现在左侧栏。点击书源进入**书源浏览器**：本地为海报墙（目录可下钻），远程为列表/海报墙切换，支持按**字母**或**加入时间**排序；点击漫画进入详情页阅读。

### 2. 百度网盘

百度网盘通过官方开放平台 API 直连，OAuth 授权一次即可，token 自动刷新。

**前置条件：注册百度开放平台应用（一次即可）**

1. 打开 [百度网盘开放平台](https://pan.baidu.com/union)（pan.baidu.com/union），登录后进入控制台；
2. 完成**个人实名认证**；
3. 创建应用，申请接入时勾选「网盘基础服务」权限（文件列表、下载等），等待审核（一般 1~2 个工作日）；
4. 拿到 **AppKey**（client_id）和 **SecretKey**（client_secret）。

> ⚠️ **AppKey / SecretKey 必填，没有内置凭据**。填写位置：「添加书源」对话框选择百度网盘后，展开「高级选项（必填 AppKey/SecretKey）」填写。

**在 app 中添加**

1. 类型选「百度网盘」；
2. 「根目录」填挂载目录（见下方目录说明）；
3. 展开「高级选项（必填 AppKey/SecretKey）」，填入自己注册应用得到的 AppKey / SecretKey（没有内置凭据，不填无法授权登录）；
4. 点「**授权登录**」：浏览器会打开百度授权页，登录你的网盘账号并点击同意（确认勾选网盘权限）；
5. 授权完成后，把页面显示的**授权码**复制回 app，点「换取 token」；
6. refresh_token 会自动填入「refresh_token」输入框，点「添加」即可。

**token 刷新与失效处理**

- 书源浏览页顶部有**钥匙图标按钮**，点击即可强制重新连接并刷新 refresh_token，成功后自动保存到书源；
- 若 refresh_token 已被百度作废（长期未使用、被同 AppKey 的其他书源顶掉、或账号解除授权），点按钮会失败并**自动打开百度授权页**，把页面显示的授权码粘贴到弹出的对话框即可完成重新授权，token 自动更新；
- 编辑书源修改了 AppKey / SecretKey / refresh_token 后保存，下次打开会自动用新凭据重连。

**目录说明**

- 百度开放平台规定，第三方应用只能访问 `/apps/<产品名>` 目录（用户网盘里显示为「我的应用数据/<产品名>」）。
- 建议：把你注册应用时填写的产品名对应的目录作为漫画目录，例如产品名是 `RCH`，就在网盘里把漫画放在 `/apps/RCH/` 下，根目录填 `/apps/RCH`。
- 也可以填 `/` 浏览整个网盘，但只有 `/apps/<产品名>` 下的内容是官方保证可用的。

### 3. 115 网盘

115 提供两种连接方式，在「添加书源」对话框里二选一（扫码获取 Cookie 为默认入口）：

| 对比项 | 方式 A：扫码获取 Cookie | 方式 B：官方 APP ID |
|---|---|---|
| 需要申请 | 不需要，扫码即用 | 需要到 115 开放平台申请（审核约数天） |
| 认证 | 115 App 扫码，自动获取登录 Cookie | 开放平台设备码扫码，refresh_token 自动续期 |
| 接口 | 非官方 Web 接口（webapi / proapi） | 官方开放平台 API |
| 稳定性 | 逆向接口，可能随官方调整（内置容错与清晰报错） | 官方接口稳定，但受开放平台规则约束 |
| 下载上限 | 无 200MB 限制（chrome/downurl 直链） | 无 200MB 限制（官方 downurl 直链） |
| 失效处理 | Cookie 过期后重新扫码即可 | refresh_token 被顶掉/过期后重新授权 |

**方式 A：扫码获取 Cookie（无需 APP ID，默认）**

1. 类型选「115 网盘」；
2. 「根文件夹 ID」留空 = 网盘根目录；也可以填某个文件夹的 ID 只挂载该目录（在 115 网页端进入目标文件夹，复制 URL 中 `cid=` 后的数字）；
3. 点「**扫码获取 Cookie（无需 APP ID）**」：app 内显示二维码，用手机 **115 网盘 APP** 扫码并确认（115 App 扫截图容易报错 / 无法识别，改用**微信扫截图**、通过 115 小程序确认，效果相同）；
4. Cookie 自动填入，点「添加」。

展开「高级选项」可切换扫码设备：默认 `wechatmini` / `tv` 等冷门设备，避免挤掉网页端 / App 旧登录；`web` 会顶掉网页端登录；Windows / Mac / Linux 客户端已下架不可选。

**方式 B：官方 APP ID 模式**

1. 到 [115 开放平台](https://open.115.com) 申请 APP ID；
2. 展开「高级选项（扫码设备 / 官方 APP ID 模式）」→ 填 APP ID → 点「官方模式：APP ID 扫码授权」；
3. 授权成功后 refresh_token 自动填入，点「添加」。

**注意事项**

- 两种方式获取的都是登录凭证（Cookie / refresh_token），明文保存在本机 SQLite，注意不要泄露。
- 方式 A 的 Cookie 有有效期：**失效时应用会自动弹出扫码框续期**（扫码成功后自动替换 Cookie 并重连）；也可在编辑书源时点「重新扫码获取 Cookie」手动续期；同设备重复扫码会顶掉旧登录。
- 方式 B 同账号同应用最多同时存在 2 个有效 refresh_token，重复授权会顶掉最早的一个（旧书源失效，删除重建即可）。
- **两种方式都没有 200MB 下载上限**（200MB 限制只存在于 115 网页版简易下载接口，RCH 未使用该接口）。

### 4. 夸克网盘

夸克通过非官方 Web 接口访问，使用浏览器 Cookie 认证，不需要申请开发者凭据。

1. 用浏览器打开 [pan.quark.cn](https://pan.quark.cn) 并登录；
2. 按 **F12** 打开开发者工具 → 「网络（Network）」→ 刷新页面；
3. 随便点一个请求，在「请求头」里找到 `Cookie` 一栏，整段复制（形如 `stoken=...; pds=...; __puus=...`）；
4. 回到 app，类型选「夸克网盘」，把 Cookie 粘贴到「Cookie」输入框；
5. 「根文件夹 ID」默认 `0`（网盘根目录），也可以填文件夹 ID 只挂载该目录；
6. 点「添加」。

**注意事项**

- Cookie 相当于登录凭证，有一定有效期，失效后按同样步骤重新复制粘贴即可（书源编辑页可直接改 Cookie）。
- 不要在公共场合泄露 Cookie。

### 5. WebDAV / SFTP / SMB

**WebDAV**（NAS / 支持 WebDAV 的网盘）

- 「服务器地址」：如 `https://nas:5006/dav`；
- 「用户名」/「密码」：WebDAV 账号；
- 「初始路径（可选，默认根目录）」：只挂载某个子目录时填写。
- 添加时自动探测是否支持 Range 分段读取：支持则流式阅读，不支持则首次整本下载到本地缓存。

**SFTP**（密码认证的远程书架）

- 「服务器地址」：`192.168.1.10` 或 `nas:2222`（带端口时可不填端口字段）；
- 「端口（默认 22）」、「用户名」、「密码」；
- 「初始路径（可选，默认 /）」。

**SMB**（局域网共享）

- 「共享目录路径（UNC）」：直接填 `\\192.168.1.10\comic` 这类路径（必须以 `\\` 开头），连通性测试通过后即可浏览。

### 6. 添加后的使用

- **打开策略**：设置 → 远程书源 → 打开策略，三选一：
  - **自动（先下载，失败转流式）**（默认）：先整本下载到缓存（有进度条），失败自动转流式；
  - **优先下载整本**：网速快或想离线读时用；
  - **直接流式**：即点即读、不占缓存（要求服务端支持 Range）。
- **缓存**：整本下载/流式读取过的漫画都会进入本地缓存，二次打开秒开；可在设置 → 缓存管理面板按类型清理。
- **排序**：书源浏览器支持按字母（数字感知）或加入时间排序。
- **删除书源**：在书源上删除会同时清理该源下的阅读记录、元数据与数据库条目。

### 7. 常见问题（FAQ）

| 现象 | 原因与处理 |
|---|---|
| 百度提示登录状态失效 / 需要重新授权 | token 被轮换或过期：在书源浏览页点顶部钥匙按钮刷新；若已失效会自动弹授权页，粘贴授权码即可恢复，重启后无需重复授权 |
| 夸克书架打不开 / 提示 Cookie 失效 | 重新去 pan.quark.cn 复制 Cookie 并更新书源 |
| 115 旧书源突然失效 | 官方 APP ID 模式：被顶掉了 refresh_token，删除旧书源重新授权；扫码 Cookie 模式：Cookie 过期，编辑书源重新扫码替换 |
| 115 扫码时 115 App 扫截图报错 / 无法识别 | 115 App 扫一扫对截图二维码兼容性较差（官方社区亦有反馈）；改用**微信扫截图**、通过 115 小程序确认即可；二维码有效期约 2~3 分钟，确认要快 |
| 更新下载慢 / 失败 | 国内访问 GitHub 慢属网络问题：设置 → 关于与更新 → 下载通道选一个镜像；应用会自动更新镜像列表并在失败时切换通道，也支持自定义镜像前缀 |
| 远程下载慢 | 百度普通用户限速与会员等级相关（官方限制，非软件问题）；可改用「优先下载整本」离线读 |
