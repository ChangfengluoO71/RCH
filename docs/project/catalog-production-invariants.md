# 离线刮削与标签生产约束

## 标签投影

刮削 proposal 的内部字段不会原样成为用户标签。自动物化只投影稳定、可读的资源语义：

- `无修正`、`有修正`
- `彩漫`、`彩页`、`黑白漫`
- `合集`、`未完结`、`全本扫描`
- `中文翻译`、`机翻`、`人工翻译`
- `数字版`、`实体版`、`单行本`、`连载`
- `汉化组：名称`

章节号、平台、出版源、发行事件和 parser 内部命名空间不会进入标签管理界面。启动时会把旧版 `resource:*`、`sequence:*`、`publication:*`、`release:*` 以及已知英文同义词迁移到上述中文标签；未知内部标签会删除，普通用户标签保留。

## 详情与阅读

作品标题、中文标题、作者、类别、系列和资源标签同时显示在漫画详情页。标签关联独立于 `BookMeta.tags`，编辑标题或作者不会覆盖自动刮削标签、已读状态或 AI 标签。

标签结果使用逻辑 `book_key` 解析回持久化目录中的物理路径，因此 `.zip/.cbz` 等共享逻辑 key 的资产仍能按真实扩展名打开。解析只读本地 SQLite catalog；不会为标签结果刷新远程目录。

## 自动流程与删除

自动流程顺序为：

1. 刷新本地目录快照/读取已持久化远程快照；
2. 执行既有同步；
3. 再次读取快照；
4. 清理目录墓碑和失效记录；
5. 重载 Dart 仓库；
6. 运行零内容读取的 catalog parser；
7. 将 `Ready` 且无冲突 proposal 写入本地元数据和中文标签；
8. 对目录、删除或物化产生的本地变更执行同步推送。

删除一个物理资产时，Rust 数据层会删除该 asset 的 proposal、queue、materialization 记录。只有同一逻辑作品不存在其它 live archive alias 时，才会继续删除阅读记录、作品元数据、标签关联、无引用标签和 AI 任务。删除书源、同步删除和目录刷新共用同一清理语义。

刮削本身仍然是 local-first：不会打开漫画内容，不调用 `ByteSource`，不读取 WebDAV/SFTP/115/夸克等远程书源。自动刮削只使用本地持久化快照和同步结果；远程在线目录对齐属于独立、显式触发的 discovery lane，不由刮削任务隐式启动。
