# RCH v0.6.2 更新介绍：把「E 站」接成一条自动化流水线

> 下载：<https://github.com/ChangfengluoO71/RCH/releases/tag/v0.6.2>
> Windows：`RCH-0.6.2-windows-x64.exe`｜Android：`app-arm64-v8a-release.apk`（另有 armeabi-v7a / x86_64 两个 ABI 包）

这一版把 E-Hentai 从"一本本手动找、手动认"变成两条能配合的线路：

- **EH 订阅**：按你写好的规则，把命中的画廊**种子**自动收进一个文件夹；
- **E 站自动刮削**：把库里已有的书**认出来**，中文标签、作者/系列、作品名一次写对。

两者是流水线关系：**订阅负责"收"**（顺带生成本地清单），**刮削负责"认"**（把清单和库里的书对上）。

---

## 一、EH 订阅（可选插件）：按规则自动收种子

入口：**设置 → EH 订阅（可选插件）**

### 默认规则长这样（每条都可改）

| 规则 | 默认值 | 说明 |
| --- | --- | --- |
| 搜索 | `language:chinese$ uncensored` | 直接用 EH 搜索语法 |
| 评分 | ≥ 4.0 | EH 搜索本身**不支持**按评分筛，这一层在本地过滤 |
| 主标题标记白名单 | `Digital\|DL版\|DL` | 填 `any` 表示不筛；实测 `[Digital]`/`[DL版]` 出现在主标题里而不是标签里 |
| 排除标记 | `AI Generated` | 命中即跳过 |
| 分档下载数 | 5 年以上 ≥1000｜2 年以上 ≥700｜半年以上 ≥500｜1 个月以上 ≥300｜最新的 ≥200 | 时间越久要求越高，避免收进冷门死种 |
| 每轮页数 | 10 页（每页 25 条） | 跟随站点游标翻页；**每页约 40–60 秒**，10 页约 7–10 分钟 |
| 请求间隔 | 2.5 秒（下限 0.5） | EH 对高频请求有限流，不建议调更小 |
| 主站 | `e-hentai.org` | 不可达时可改镜像域名；**种子直链固定在 `ehtracker.org`，改这里不影响种子下载** |

面板里还有 **可达性预检**与**连通性检查**（主站/镜像一次看清），点「开始扫描」前就能知道通不通；
扫描可**停止**、可**打开目录**，跑完给出进度与每一条失败原因；不满意可一键「恢复默认规则」。

### 它产出什么

- 命中画廊的 **`.torrent` 文件**，全部放进你选定的目录；
- 外加一份 **`manifest.json` 清单**（本地元数据，供"E 站自动刮削"回退使用）。

种子拿到后交给你的下载工具即可 —— RCH 不替你下载图片。

### 三个硬边界（写给你放心）

1. **只读来源**：只访问 EH 的元数据接口和 `.torrent` 文件，**不读图片、不解析压缩包内容**；
2. **只写一个出口**：只写你选定的那个目录（`*.torrent` + `manifest.json`），
   **不碰书源、数据库、元数据与阅读记录**；
3. **不自动运行**：必须由你在设置里显式点「开始扫描」，不会在后台自己跑。

## 二、E 站自动刮削：让库里的书自己认领中文信息

入口：**设置 → E 站自动刮削**（与「智能刮削」并列）

### 用法就三步

1. 选**一个书源的某个文件夹**作为刮削范围；
2. 点「开始」；
3. 看结果 —— 自动写入的与需要你确认的会分开列出。

### 它和"瞎猜"的区别

- **只对已刮削过的书工作**：匹配输入取的是 M8 刮削解析出的**干净作品名**，
  而不是拿原始文件名去硬猜；
- **先实时搜索**，搜不到才回退本地 `manifest.json`（并明确提示"覆盖较窄"，不假装成功）；
- **只有作品名唯一命中才自动写库**；歧义（`Ambiguous`）与未命中（`Unmatched`）**零写入**，
  只进预览等你确认；
- **只增不覆盖**：命名空间标签全量导入（中文优先），`author` / `series` 等空白字段顺手补齐，
  已有内容不会被冲掉；
- **命中依据如实显示**：不会把"创作者兜底"当成作品名命中而误写。

### 导入进来的标签怎么用

- 按来源**分色方框**，一眼看出哪些是 E 站导入的；
- 标签面板里有 **`源:e站` 置顶行**，点进去就是这批书；
- 某本书不想要这些标签，点一下就能**隐藏该书的 E 站导入标签**；
- 想一本本过目：详情页里可以**逐本预览**，先看「匹配输入」再决定是否导入。

## 三、两条线路怎么配合

```
EH 订阅（设置 → EH 订阅）
  └─ 按规则扫描 → 保存 *.torrent + manifest.json（本地清单）
                              │
E 站自动刮削（设置 → E 站自动刮削）        │
  └─ 选书源 + 文件夹 → 一轮批量：先实时搜索 ─┘（搜不到时回退这份 manifest）
                     → 唯一命中自动写标签/补齐字段
                     → 歧义/未命中进预览，人工确认
```

- 第一次用，建议**先跑一轮订阅扫描**把 `manifest.json` 生成出来（否则详情页逐本预览会提示
  "请先在『设置 → EH 订阅（可选插件）』里选择保存目录并运行一次扫描"）；
- 刮削的候选范围**只包含已被 M8 刮削过的书**（即已经有解析结果的书）；
  还没刮削的书，先去 `设置 → 书源与网络 → 重新刮削` 跑一轮。

## 四、这一版顺带一起的更新

- **卷 / 话（章节·部号）**：详情页标题、「E 站自动刮削」结果行、导入预览的「匹配输入」统一显示
  「作品名 + 话号」；号码会随**同步**与 **`.rchpkg` 备份**一起走（换设备/恢复后仍在）；
  解析不出号码时**不显示、不默认 1**。
- **条漫**：修掉快速下拉时"划着划着突然跳回好几页前"（页高从占位收敛到真实高度时补偿滚动位置，
  不再把可见内容推走）。
- **阅读器**：分页改为按视口推进（修掉末页配对越界导致的永久转圈）、边界提示覆盖条漫与镜像方向、
  到达末页 3 秒后提示"再随机一本 / 退出到详情页"。
- **进云端书源更快**、**点更新后直接进下载并安装界面**、设置页拆分出独立的「关于与更新」折叠栏。

## 五、已知限制

- 订阅只产出**种子与清单**，不下载图片；需要你的下载工具接力。
- 需要能访问 e-hentai.org（或你填的镜像域名）；面板里有连通性预检。
- **一轮扫描有真实耗时**：每页约 40–60 秒（默认 10 页约 7–10 分钟），页数越大覆盖越广、耗时越长。
- 自动刮削的召回率取决于"作品名唯一命中"这条保守规则 —— 宁可少写，也不写错；
  歧义项会留在预览里等你确认。
- Android 安装包使用正式签名；若你曾装过**开发测试包**，需先卸载再安装（会清应用数据）。
