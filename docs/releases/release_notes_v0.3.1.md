# RCH v0.3.1

## 新增

- **阅读器页面旋转**：右键"界面旋转"，支持对单页独立旋转，每页旋转结果自动记住，下次打开不变
- **本地漫画自动转 CBZ**：刷新时后台自动把漫画文件夹 / zip 打包为 CBZ（可在全局设置关闭）；转换后与原内容视为同一本，进度、标签无缝延续
- **后缀名变更识别**：`zip` 改名 `cbz` 后仍识别为同一本书
- **标签管理分层折叠**：元数据标签按 作者 / 类别 / 系列 / AI超分 / 状态 分组，独立展开收起
- **最近阅读 / 最多阅读**点击进入漫画详情页
- **漫画排序**：按字母（数字感知）/ 按加入时间（最新在前）
- **AI 超分任务列表**：悬浮窗展开可拖拽调整排队顺序，进行中任务置顶，重启后顺序保持

## 修复

- 阅读器翻页 / 双页缩放后拖动失效
- 移除 DEBUG 角标与阅读设置弹窗溢出黄条

安装包：`RCH-v0.3.1-windows-x64.exe`
