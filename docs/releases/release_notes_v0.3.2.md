# RCH v0.3.2

## 新增

- **百度网盘书源**：直连百度开放平台官方 API，浏览器授权一次即可浏览 / 阅读 / 缓存网盘漫画
- **115 网盘书源**：直连 115 生活开放平台官方 API，应用内扫码授权，支持根文件夹挂载
- **SFTP 书源**：密码认证远程书架，流式读取 + 整本缓存
- **SMB 书源**：UNC 路径（`\\NAS\漫画`）直通本地文件系统
- **远程书源打开策略（全局设置）**：自动（先下载、失败转流式）/ 优先下载整本 / 直接流式，四种远程书源通用
- **自动转 CBZ 扩展到 SMB**：共享目录刷新时自动打包（全局开关控制）
- **添加书源对话框升级**：6 种类型下拉选择，网盘书源内置授权流程与高级凭证选项

## 修复

- 书源清理不再误删 SFTP 阅读记录
- 添加书源对话框超高溢出（改可滚动）
