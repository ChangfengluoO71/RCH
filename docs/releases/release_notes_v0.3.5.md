# RCH v0.3.5

## 新增

- **多端同步（本地优先，无服务器）**：标签 / 书源配置 / 漫画详细信息 / 阅读进度 / 设置全量增量同步，标准包格式（`.rchpkg`）版本化导出导入
- **两种传输通道**：网盘同步盘目录（OneDrive / 坚果云 / 百度同步空间等本地文件夹）与 WebDAV（独立书源配置 + 自定义远程目录 + 测试连接）
- **增量合并**：按行 LWW（`updated_at` 新者胜）+ 墓碑，删除跨设备传播、不复活已删项
- **幽灵书源**：其他设备的本地书源以"仅元数据"显示，可编辑回传、不可阅读；全局"跨设备搜索"开关
- 设置页"备份 / 同步"面板：手动推送 / 拉取 / 恢复、归档清理（本地目录 + WebDAV DELETE）

## 优化

- SQLite 同步元数据落库（`updated_at` / 墓碑 / 设备 / 游标 / 别名表），老库启动自动迁移
- 书源凭据永不写入同步包；导入保留目标端本地凭据，新书源为"待填凭据"状态
- WebDAV 新增上传 / 下载 / 建目录 / 删除原语（不依赖 Range）

## 修复

- 设置启动加载崩溃：`keys`（键盘绑定）历史落库为非法 JSON（Dart `Map.toString()`），导致 SQLite 加载回退；改为 `jsonEncode` 落库并兼容历史坏数据
