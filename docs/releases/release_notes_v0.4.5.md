# RCH v0.4.5 — 百度网盘 token 刷新/重新授权 + 文件夹封面

## 新增

- **百度网盘 refresh_token 手动刷新**：书源浏览页顶部新增钥匙按钮，点击强制重新连接并刷新 refresh_token，成功后自动保存到书源；
- **失效自动重新授权**：refresh_token 被顶掉/过期时自动打开百度授权页，弹窗粘贴授权码即可恢复，无需再手动编辑书源；
- **文件夹封面（全本地）**：远程网盘子目录封面基于本地快照与阅读记录判定，下载完成后自动刷新；
- **书源同步导出补全**：手动导出到文件 + 加密书源凭据包 + Android 降级。

## 修复

- 115 / 阅读器：缓存书离线可读；扫码对话框矮屏溢出修复；
- 设置加载容错：SQLite 中 updateMirrorList 损坏时不再回退 JSON 模式。

## 发布

- Windows 安装包与 Android APK（arm64-v8a / armeabi-v7a / x86_64）由 GitHub Actions 自动构建、正式签名并附到最新 Release
