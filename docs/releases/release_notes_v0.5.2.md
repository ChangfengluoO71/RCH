# RCH v0.5.2

## 新增

- **阅读统计界面**（原「最多阅读」升级）：统计最多阅读的**漫画 / 系列 / 标签 / 作者 / 类别**各 Top10；漫画条目点击跳转漫画详情页，系列/标签/作者/类别点击直达标签管理对应标签的详情列表。
- **「清空全部缓存」分列确认**：最近阅读记录（删列表与进度）与阅读统计（仅次数归零、保留进度）分别勾选确认，只清空用户同意的内容。
- **标签详情书名显示离线索引真实文件名**：夸克/115 等 id-path 书源不再把 32hex 素材 id 当书名显示。

## 修复

- **清理失效漫画数据无效（远程删除漫画后缓存与数据库残留）**：墓碑收集改用专用查询（原接口 SQL `deleted=0` 过滤导致墓碑证据恒为空，前两版修复均被该层拦截）；点击时先**在线核对远程书源**（枚举全树、消失条目自动墓碑化，核对失败的书源保守保留并提示）；失效记录**联动删除元数据**（此前只删记录行，本地删文件/远程删漫画时标签、封面残留）与 page/raw/cover 缓存、AI 任务残留。
- **编辑元数据标签冲掉「已读」状态**：全量替换标签关联时保留「已读」（自动/手动独立维护的关联）；手动取消过已读的书不会被自动恢复。

## 提示

- Android / Windows 均建议在应用内「关于与更新」检查并安装新版本；也支持从本 Release 直接下载对应平台安装包。
