# RCH v0.5.4 — 离线刮削自动化与书源清理

发布日期：2026-08-24

## 新增功能

- **离线智能刮削**：根据文件名、父级目录、祖先目录和同目录序列识别作品名、作者、系列、章节、合集及资源属性。
- **自动写入元数据和标签**：Ready 且无冲突的刮削结果会自动写入漫画元数据和标签，并保留用户手工修改。
- **可读标签**：将中文翻译归并为 `Chinese`，无修正归并为 `无修正`，`DL/DL版`归并为 `高清`。
- **详情页信息补充**：显示作品名、作者、系列、资源标签和原始文件名，原始文件名支持选择复制。
- **刮削流程简化**：设置中的刮削操作统一为“重新刮削”。
- **书源刷新与清理**：新增或编辑书源后自动刷新；确认删除书源时同步清理相关阅读记录、元数据、标签关联和缓存数据。
- **本地优先**：刮削只使用本地目录快照，不读取漫画内容，也不主动访问远程书源。

## 修复问题

- 修复作者、系列等元数据标签与漫画详情页显示不一致，以及从标签进入漫画后无法正常阅读的问题。
- 修复重复刮削产生重复标签、重复作品和用户手工元数据被覆盖的问题。
- 修复不同扩展名文件被错误合并、刮削结果数量与输入文件数量不一致的问题。
- 修复本地、夸克和 115 书源目录归一化错误导致的作品名覆盖、章节序列识别错误等问题。
- 修复书源刷新失败时误清理本地数据的问题；确认删除后可完整清理阅读记录、元数据、标签关联和缓存。
