# RCH v0.5.4

## 新增

- 离线目录快照刮削自动化：自动生成 proposal，并将无冲突的 Ready 结果写入元数据和标签。
- 漫画详情页显示作品名、作者、系列等识别结果，并支持复制原文件名。

## 修复

- 作者/系列元数据标签与详情页保持一致，标签入口可正常打开对应漫画。
- 标签词汇统一为用户可理解的 `Chinese`、`无修正`、`高清`，移除无意义的内部投影标签。
- 书源增删改即时刷新，115 根目录变更生效；远程删除确认后完整清理相关记录、元数据、标签、AI 任务和缓存。
- 保持智能刮削零内容读取、零远程书源 I/O，并修复重复投影与资产统计一致性问题。

完整变更记录见 [CHANGELOG](../project/CHANGELOG.md)。
