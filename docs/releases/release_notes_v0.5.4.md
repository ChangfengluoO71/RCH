# RCH v0.5.4 — 离线刮削自动化与书源清理

发布日期：2026-08-24

## 这次更新解决什么问题？

v0.5.4 把“目录里有什么漫画”到“漫画库里显示什么信息”之间的流程真正连起来：

```text
本地目录 / 已索引的远程目录
        ↓
生成本地 Catalog Snapshot
        ↓
离线解析文件名、父级目录和同目录序列
        ↓
生成可解释的 proposal
        ↓
Ready 且无冲突的结果自动写入元数据与标签
        ↓
进入现有同步队列
```

整个流程仍然遵守 Local-first 边界：刮削器不会为了补信息去打开漫画文件、读取 ZIP/CBZ/PDF/EPUB、读取封面或页面，也不会主动访问 WebDAV、SFTP、115、百度网盘或夸克网盘。

## 新增功能

### 1. 离线智能刮削自动化

- 刮削只使用本机已经保存的文件名、父级/祖先目录、同目录文件列表和本地 catalog/index 数据。
- 文件名中可以区分作品名、作者、circle/artist、章节、前后篇、续篇、合集、翻译状态和资源属性。
- 只有完整内容已经存在于本地文件或 raw cache 时，后续层才有机会读取内容；本轮 catalog 刮削本身不会读取任何字节。
- 远程文件即使尚未缓存，只要它已经被本地索引记录，也可以用文件名和目录上下文生成 proposal。
- 设置中的刮削界面精简为“重新刮削”，适合用户调整了本地文件夹或远程目录快照后重新运行。

### 2. Ready proposal 自动进入元数据与标签

- `Ready` 且没有冲突的 proposal 会自动投影到漫画元数据和用户可见标签。
- 投影过程是幂等的，重复刮削不会重复创建标签，也不会因为旧 proposal 状态而跳过必要的修复。
- 用户手工填写的标题、作者、系列和手工标签会被保留；自动结果只补充空缺或稳定的生成字段。
- 作品名、作者、系列现在同时出现在标签管理和漫画详情页，不再只存在于后台标签表。
- 标签入口使用真实的本地/索引资产定位，点击标签中的漫画可以正常打开阅读。

### 3. 更容易理解的资源标签

本版本只保留对用户有实际价值的稳定标签：

| 文件名信息 | 用户看到的标签 | 说明 |
|---|---|---|
| `[中国翻訳]`、`[中国翻译]`、`[中文]` | `Chinese` | 表示资源包含中文翻译 |
| `[無修正]`、`[无修正]` | `无修正` | 表示当前资源的无修正属性 |
| `[DL版]`、`[DL]` | `高清` | 按本项目语义表示高清资源，不再显示“数字版” |

内部序列类型、解析状态和无意义的投递标记不会再作为普通标签显示。作者、系列、汉化组等确定的本地信息仍会按对应角色分类保存。

### 4. 详情页补充原文件名

漫画详情页现在会显示：

- 识别后的作品名
- 作者/创作者
- 系列
- 可见资源标签
- 原始文件名

原文件名可以直接选择和复制，便于核对刮削结果或反馈规则问题。

### 5. 书源配置与删除清理

- 新增或编辑书源后，书源树会在保存完成后立即刷新，不需要重启应用。
- 115 和夸克的根目录 ID 会统一作为实际浏览、索引和清理根目录；留空时使用根目录 `0`。
- 远程删除清理只有在成功完成远程对齐后才会执行；刷新失败或无法确认远程状态时不会把“看不到”误判成删除。
- 确认删除后，会联动清理阅读记录、作品元数据、标签关联、孤立标签、AI 任务以及 page/raw/cover 等缓存。
- 仍然保留用户已有的共享标签：只有不再被任何漫画使用的孤立标签才会被删除。

## 用户建议操作

1. 升级后先打开书源，让本地书源或远程书源完成目录索引。
2. 进入 `设置 → 刮削`，点击唯一的 `重新刮削` 按钮。
3. 在漫画详情页检查作品名、作者、系列和原文件名。
4. 在标签管理中检查 `Chinese`、`无修正`、`高清` 及作者/系列标签。
5. 确认结果后再执行同步；刮削本身不会主动连接远程书源。

## 本版本明确不包含

- AniList、Bangumi、MangaDex 等在线 Provider 查询
- OCR、封面识别、pHash、CLIP、向量检索
- 文件名纠错或外部 canonical name 修正
- 为刮削主动刷新远程书源目录
