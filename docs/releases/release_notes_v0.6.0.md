# RCH v0.6.0

自 v0.5.7 以来落地了一批新能力（远程书源海报墙与扫描、扫码登录、封面重抓、阅读渲染宽度等），
同时把各格式的打开路径改为按需读取。以下按 新增 / 改进 / 修复 列出。

## Added

- 远程书源支持完整的海报墙与扫描：扫描进度、封面进度（可用 / 等待 / 进行中 / 失败）都在书架顶部展示。
- 夸克书源支持扫码登录，不必再从浏览器开发者工具复制 Cookie。
- 115 网盘支持扫码获取 Cookie（无需申请 APP ID）；根文件夹 ID 可用「选择文件夹」自动填入。
- 保存过的书源凭据在启动时自动重连，不必每次手动登录。
- 新增「阅读渲染宽度」设置：省流 1080 / 标准 1600 / 跟随屏幕；三个档位的页面缓存相互独立。
- 新增「阅读完成后自动删除整包」：读完即释放整本包，封面缓存保留。
- 新增整本下载缓存上限（2 GiB）：超出后自动删除最旧的整本包，始终保留最新在读的。
- 新增封面重抓：在书源页面点「刷新」会重新排队该来源当前档位下失败的封面。
- 设置项按类别折叠：阅读 / 书源与网络 / 缓存与存储 / 同步与备份 / 外观与布局。

## Improved

- 打开 EPUB 只读取中央目录、章节按需解析：真机从约 30 秒降到 1 秒以内。
- 打开 ZIP / CBZ 只读取中央目录，耗时不再随条目数量增长（800 条目由整包读取降到 4 次以内远端读）。
- 打开 PDF 改为按需读取，不再需要先下载整本。
- 打开 MOBI 改为按需读取；第二次打开复用页表缓存，不再重复探测。
- 封面读取按格式走专用路径：MOBI 只探测第一张图；大体积 CBZ 的封面由 192 次读降到 8 次（约 9 秒）。
- 默认阅读策略改为流式优先：点开即可阅读，流式不可用时自动回退整本下载。
- 合并重复读取：同一文件的头部窗口不再被反复请求（此前同一会话可达上百次）。
- 115 与夸克书源的「原文件名」显示真实文件名，不再显示数字 ID。
- 扫描状态栏只保留「重试远程扫描」（扫描本身自动运行）。

## Fixed

- 修复详情页已有封面、海报墙却显示「获取失败」的问题（两套缓存互不相通导致）。
- 修复在详情页看到封面之后海报墙不刷新的问题。
- 修复封面失败后点「刷新」无效的问题（任务重新排队但没有被唤醒执行）。
- 修复大体积文件（80 MB 以上）封面永久失败的问题。
- 修复 Windows 安装版缺少 PDF 组件导致 PDF 无法打开、封面缺失。
- 修复封面失败原因被错误标记为「缺少运行库」（实际是渲染或解析错误）。
- 修复删除书源后 `remote_*` 数据残留、同名书源混淆、启动时残留扫描状态未回收等问题。
- 修复二维码保存到相册失败，以及若干文案与对比度问题。

## Verification

- 真机（Android）与 Windows 版：EPUB 打开 30.8 s → 0.59 s；封面可用数由 63 增至 284（失败 1）；
  MOBI 第二次打开不再重复探测；大文件封面由长期失败变为 0.7 s 打开、0.2 s 出图。
- Rust 全量测试 25 个套件 / 544 项通过；Flutter analyze 无问题。

## Android upgrade compatibility

- `versionCode` 规则：`100000 + (major × 10000 + minor × 100 + patch)`，v0.6.0 对应 **100600**。
- 本版为正式签名包。此前安装过开发用测试包的设备需先卸载再安装（会清除应用数据）。
