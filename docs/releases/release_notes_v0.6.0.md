# RCH v0.6.0

这一版主要解决两件最影响日常使用的事：**打开漫画要等多久**，以及**封面老是刷不出来**。
另外新增了"阅读渲染宽度"设置，并把缓存管理做得更省心。

## ✨ 最直观的变化

### 打开快了很多（大文件尤其明显）

- 打开一本 EPUB：**半分钟 → 不到 1 秒**（真机实测 30.8 秒 → 0.59 秒）。
- ZIP / CBZ 漫画：打开速度**不再随页数变慢**（只读目录结构，不读整个文件）。
- MOBI：第一次打开仍需读一遍页表（大文件十几秒），**第二次打开几乎瞬间**（不再重复探测）。
- 翻页/滚动时不再重复下载已经读过的同一段数据（此前同一段文件头会被反复请求上百次）。
- 默认改为**流式阅读**：点开就能看，不必等整本下载；网络不稳时自动退回整本下载。

### 封面终于稳了

- 修掉一大批"**详情页能看到封面、海报墙却显示获取失败**"的情况（本地已有的图现在会直接使用）。
- 在详情页看过封面之后，**海报墙会立即刷新**（此前不会）。
- 封面失败后可以在书源页面点「**刷新**」重新排队重试（此前点了没用：任务排进去了却没人执行）。
- 超大漫画（80 MB 以上）的封面此前会**永久失败**，现在能正常抓到（实测 0.7 秒打开、0.2 秒出图）。
- 修复了 Windows 安装版**缺少 PDF 组件**导致 PDF 打不开、没有封面的问题。

### 文件显示与登录

- 115、夸克书源里的「原文件名」不再显示一长串数字 ID，而是**真实文件名**。
- 支持夸克扫码登录。

## 🆕 新增与调整的设置

| 设置 | 位置 | 说明 |
|---|---|---|
| **阅读渲染宽度** | 设置 → 阅读渲染宽度 | **省流 1080 / 标准 1600 / 跟随屏幕**。想省流量或让翻页更轻快选"省流"；在意清晰度保持"标准"（与旧版完全一致，不会让已有页面缓存失效） |
| 阅读完成后自动删除整包 | 设置 → 缓存相关 | 省空间：读完自动删除整本下载的包，**封面缓存保留** |
| 设置项按类别折叠 | 设置页 | 设置项变多了，现在按类别收起，找起来更快 |

## 🧹 缓存更省心

- 整本下载缓存新增 **2 GiB 上限**：超出后自动删除**最旧**的整本包，并始终保留最新在读的那本
  （此前只增不减，只能手动清空）。
- 清整本缓存**不会**连带清掉封面缓存，反之亦然。

## 🔧 其它修复与打磨

- 扫描状态栏去掉了「暂停 / 增量重扫 / 全量重扫」三个按钮（扫描本来就是自动运行的），只保留「重试远程扫描」。
- 修复二维码保存到相册失败；修正若干文字对比度与提示文案。
- 目录刮削与标签元数据相关的一批修复（目录识别规则、资源归一化、标签清理）。

## ⬆️ 升级说明

- **Windows**：下载 `RCH-0.6.0-windows-x64.exe` 覆盖安装即可（安装器会自动关闭并重启应用）。
- **Android**：下载 `app-arm64-v8a-release.apk`（较老的机型选 `armeabi-v7a`，模拟器选 `x86_64`）。
  - 本版为**正式签名**包。如果你之前装的是开发用测试包，需要**先卸载再安装**
    （会清空应用数据：本地书目与缓存，请先做好心理准备或重新扫描书源）。
- 应用内「设置 → 关于与更新」也会提示本版本，可直接在应用里更新。
