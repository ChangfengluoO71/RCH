# RCH v0.6.1

本版重点是 **WebDAV 书源的封面链路**：修复了该类型书源在启动后无法建立会话、进而导致封面任务
一直停在"等待"的问题，并补上了索引中文件大小的通路。

## Fixed

- 修复 WebDAV 书源启动后**无法建立会话**的问题：会话探测会对书源根目录（集合）发一次带 Range 的
  请求，而部分 WebDAV 服务（实测 Alist / OpenList）对集合返回 `405`，此前会被判定为登录失败。
  现在这一类状态码视为"集合层不支持探测"，不再中断登录（读取路径对不支持 Range 的服务本就
  有整本回退）。
- 修复"**点刷新后封面毫无反应**"：任务确实被重新排队，但因上一条导致该源没有会话，
  队列始终无人处理，现象就是一直不动。
- 修复索引中**文件大小缺失**：浏览或离线索引目录时，此前会把大小写成空，导致封面抓取判定
  "拿不到文件大小"而失败（大文件尤为明显）。现在会把远端返回的大小写入索引。

## Added

- 扫描的**后台自愈**：当索引中存在"大小未知"的文件时，扫描会在既有的目录重查周期内自动重新
  列一遍目录，让远端真实大小落库（WebDAV 场景如仍显示失败，点一次「离线索引」可立即补齐）。

## Improved

- 封面读取失败时新增**可判读的诊断**：日志会记录失败发生的步骤与 HTTP 状态类别
  （不含书源原文、地址或凭据），便于以后定位同类问题。
- 会话预热失败时会记录**是哪个书源、失败类别**（此前只记一个失败计数）。

## Verification

- Rust 全量测试：**546 项通过 / 0 失败**（含 `-D warnings` 门禁）。
- Flutter 全量静态检查无问题；Flutter 测试 **204 项通过 / 1 项按环境跳过**（该用例需要已编译的
  Rust 动态库，缺失时明确跳过而不是失败）。
- WebDAV 真机：会话恢复正常后，封面队列从"全部失败"转为持续出图（实测短时间内可用数由 19 增至 84 以上）。

## Android upgrade compatibility

- `versionCode` 规则：`100000 + (major × 10000 + minor × 100 + patch)`，v0.6.1 对应 **100601**。
- 本版为正式签名包。此前安装过开发用测试包的设备需先卸载再安装（会清除应用数据）。
