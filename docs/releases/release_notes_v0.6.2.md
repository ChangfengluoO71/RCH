# RCH v0.6.2

本版集中缩短"进入云端书源"的等待时间，并把"更新"与设置入口的交互调整到更符合直觉的位置。

## Improved

- **进入云端书源更快**：此前每次进入都会重新登录一次（列目录 + 分段读取探测 + 往返测速各一次，
  实测局域网 WebDAV 上首次请求约 1.8 秒）；现在会复用启动时已建立的会话，
  浏览过的书源再次进入基本无需等待。
- **建立会话少两次往返**：往返测速不再固定发送 3 次 HEAD（部分 WebDAV 服务对 HEAD 返回 405，
  纯属浪费），改为复用一次成功请求的耗时。副产品是并发档位回到真实水平，扫描与封面也更快。
- **扫描为前台让路**：正在阅读或浏览时，后台扫描会在每个目录之间短暂让出，
  不再与前台请求抢占同一个连接；空闲时扫描速度不受影响。

## Changed

- **点更新后直接进入可见的下载与安装界面**：显示版本、下载进度与安装包保存位置，
  下载完成自动进入安装。Windows 改为显示安装向导（此前为静默安装，用户下载完还需要自己去临时目录找安装包）。
- **设置页新增独立的「关于与更新」折叠栏**（此前与「同步与备份」混在一起），设置分组现在为：
  阅读 / 书源与网络 / 缓存与存储 / 同步与备份 / 外观与布局 / 关于与更新。

## Added — 「E 站自动刮削」（元数据导入）

- **设置 → 书源与网络 →「E 站自动刮削」**：按书源 + 文件夹批量识别，**只有作品名唯一命中**才自动写库；
  其余进预览待确认，`Ambiguous` / `Unmatched` **零写入**。
- **匹配引擎**（纯函数）：Dice 相似度 + 阈值 0.5、同卷/并列保护、锚点以**作品名**优先；
  候选源改为**实时搜索**（带回标签语义）、匹配输入改用 M8 解析标题而非原始文件名 —— 这是一轮识别率根因修复。
- **导入规划器（影子模式）**：命名空间前缀 + 中文优先、**只增不覆盖**；应用阶段可补齐 `author` / `series`
  空白字段（复用 `updateMeta`，只填空）。
- **预览弹窗**：命中依据如实带出（创作者兜底不再被当成作品名误命中）；确认后写入前缀标签。
- **标签**：内置 1369 条中文翻译基线（缺失按需更新）、按来源分色方框、`源:e站` 置顶行、点击可隐藏该书导入标签。
- **manifest 语义层**：对齐刮削 `semantic`（`work_title` / `creators` / `source_series` / `censorship` / `tags_zh` 等）。

## Added — 卷 / 话（章节、部号）显示与同步

- **落库与显示**：`book_metas` 物化 `volume` / `chapter`（此前解析值被丢弃）；详情页信息区标题、
  「E 站自动刮削」结果行、导入预览的「匹配输入」统一按「作品名 + 话号」显示；
  **解析不到号码则不显示、不默认 1**。
- **跨设备传播**：两列随同步快照载荷与 `.rchpkg` 备份一起走（`MetaSyncRow` 以 `serde(default)` 兼容旧包/旧节点），
  落库两处都遵守「空值不覆盖」；同时修掉两条既有收敛缺陷（无 base 时整条丢弃 metas 条目 ⇒ 永不收敛；
  合并结果未对齐落库状态 ⇒ 每轮重推）。
- **墓碑语义（ADR-030「墓碑随行复活而失效」）**：墓碑只对**比它旧**的行有效 —— 导出读时过滤 + 应用时看时间 +
  写活行即清墓碑。整包恢复到全新库由 1055 行 / 111 章节回到 **1154 行 / 卷 2 / 章节 177**。

## Fixed — 阅读器

- **条漫快速下拉"突然跳回好几页"**：根因是无 `itemExtent` 的列表在**视口上方**的页由占位高度收敛成真实高度时，
  只保持像素偏移 ⇒ 可见内容被整体推走。现按「旧底边是否仍在视口顶边之上」等量补偿滚动偏移
  （`position.correctBy` 静默纠偏，**不打断快速下拉的惯性**），并在字节到达时预告占位高度；
  手机实机 50+ 页不等高条漫快速下拉验证通过。
- **分页按视口推进**：修掉末页配对越界导致的**永久转圈**，翻过末尾给出提示。
- **边界提示**：下沉到 `_go()`，覆盖**条漫模式与镜像方向**（点按 / 键盘两种模式）。
- **末页体验**：到达末页延迟 3 秒提示（再随机一本 / 退出到详情页）；随机挑选会过滤已删除文件。
- 顺带修掉测高回调在 sliver 回收子项后打到 DEFUNCT 元素的缺陷。

## Fixed / Changed — 其他
