# RCH v0.6.3

本版本集中改进阅读器的跳页与加载体验、随机阅读候选、远程书源恢复，以及应用内更新的可靠性。

## 阅读体验

- 随机阅读从全库有效候选中选择，支持本地图片目录，并避开当前漫画和近期随机过的漫画。
- 阅读器顶栏增加随机阅读按钮，骰子图标与主页保持一致。
- 条漫远距离跳转使用统一的页面高度估算；跳转期间只加载目标和视口附近页面，减少中间占位项引发的错位与请求堆积。
- 分页阅读优先加载当前可见页，邻页在后台低优先级预取。原图字节到达后立即显示，AI 缓存可在之后替换显示版本。
- 阅读器展示打开阶段和失败重试入口；页面失败重试次数有限，避免持续转圈和无止境请求。

## 远程书源与更新

- 夸克登录凭据过期时可直接进入扫码恢复流程；远程索引缺少文件映射时可刷新书源并重试。
- 更新器校验下载包 SHA-256，并在安装前再次校验；并发下载/安装合并处理，失败后保留可用安装包与重试入口。
- Windows 构建自动准备并打包 PDFium，避免打开 PDF 时因动态库缺失而失败。
- 阅读过程中远程扫描和封面工作会为前台页面读取让路。

## 版本与安装

- Android `versionCode`：`100603`。
- Windows：下载 `RCH-0.6.3-windows-x64.exe` 后运行安装。
- Android：在 GitHub Release 资产中选择与设备 ABI 对应的 APK。
