# RCH v0.6.4

本版本改进手机端漫画浏览和宽页阅读，并增加应用配色与字体自定义。

## 手机端漫画浏览

- 海报墙支持 2、3、4 栏，适用于最近阅读、统计、标签和书源列表；桌面端布局保持原样。
- 可选择点击漫画后直接阅读。开启后，长按漫画仍可打开详情页；最近阅读、统计、标签、书源和搜索入口行为一致。
- 移除 E 站自定义主站/镜像地址输入，主站固定为 `e-hentai.org`；窄屏订阅设置控件会重新排布。

## 阅读体验

- 手机竖屏提供智能拆分、强制拆分和保持整页三种宽页处理方式。智能模式只拆分检测到明显中缝的宽页；横屏默认保持整页。
- 拆分页按漫画阅读方向排列，并允许逐页切换拆分状态。页面进度和书签仍对应原始文件页码。
- 根据阅读区域和屏幕像素密度选择渲染宽度；条漫模式将拆开的两半纵向放在同一源页项目中。

## 外观与字体

- 配色预设新增经典、海雾、暖纸和墨夜，可与白天/夜间模式分别选择。
- 应用界面字体可选系统默认、衬线、霞鹜文楷 GB 轻便版和知行行书。字体仅影响应用界面文字，不改变漫画图像。

## 版本与安装

- Android `versionCode`：`100604`。
- Windows：下载 `RCH-0.6.4-windows-x64.exe` 后运行安装。
- Android：在 GitHub Release 资产中选择与设备 ABI 对应的 APK。
