# RCH v0.6.5

本版本增加平台材质选项，完善漫画卡片布局，并让直接阅读设置同时覆盖电脑端。

## 外观

- Android 12 及以上可选系统动态配色。
- Windows 11 22H2 及以上可为主窗口选择云母材质，为对话框和底部面板选择亚克力材质；默认仍使用标准外观，不支持时自动回退。
- 亚克力弹窗和底部面板采用可见的背景模糊，同时保留文字对比度。

## 漫画浏览与阅读

- 开启「点击漫画文件不进入详细页」后，电脑端点击可阅读漫画也会直接进入阅读器；右键菜单提供「进入漫画详细页」。最近阅读、统计、标签、书源和搜索入口保持一致。
- 手机 3、4 栏海报卡片按封面比例分配空间，标题和元数据放在封面下方。
- 阅读设置说明手机竖屏宽页拆分与电脑/平板双页拼接的适用场景，避免同时启用。

## 版本与安装

- Android `versionCode`：`100605`。
- Windows：下载 `RCH-0.6.5-windows-x64.exe` 后运行安装。
- Android：在 GitHub Release 资产中选择与设备 ABI 对应的 APK。
