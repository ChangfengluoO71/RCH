# RCH v0.6.6

本版本集中改进 EH 订阅工作流、书源浏览窄屏布局、后台任务状态和 Android 存储访问提示。

## EH 订阅与筛选

- EH 扫描显示当前阶段、处理项和已保存数量；失败或取消时保留已完成结果。
- 每日完整工作流和最近运行状态集中在订阅自动化入口，本地已校验 Torrent 可从种子交接区域查看。
- 最低评分固定为 `≥4.4`；发布时间不超过 3 天（含）的作品一律跳过。
- 下载数阶梯可以按天或按年查看和编辑；标题标记筛选继续使用 `[Digital]` 等现有规则。

## 115 状态与任务退出

- BT 批次状态和只读云端任务监控分别显示已提交、下载中、完成及未知状态；应用重启后可继续只读核对。
- 退出 RCH 时，如果存在运行中的本地工作或待恢复监控，会提示哪些本地任务将暂停、哪些已接受的云端任务仍在远端继续。
- 关闭 RCH 不会继续运行本地轮询；应用关闭期间不会承诺发送状态通知。

**115 Cookie Web BT 写入仍为实验功能。** 当前 SSP 线上兼容性和完整 P0 真实闭环尚未通过；每日自动 115 写入保持门禁关闭。上传或提交响应未知时，RCH 不会将其显示为下载成功。请以 115 客户端中的真实任务与文件状态为准。

## 浏览与平台体验

- 手机窄屏下，书源浏览的离线索引、排序、视图切换、刷新和选择操作收纳到竖向“更多”菜单。
- 设置内容在宽屏和窄屏下使用一致的可用宽度并左对齐。
- Android 存储访问失败和远程书源连接失败提供更明确的说明与恢复入口。
- Windows 云母材质会跟随 RCH 当前浅色或深色主题。
