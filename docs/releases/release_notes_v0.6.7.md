# RCH v0.6.7

本版本优化 EH 自动化入口、115 BT 批次反馈和书源列表展示。

## EH 订阅与自动化

- EH 每日完整工作流可配置为 115 云下载，或只检查、校验并保存本地 Torrent。非 115 模式不会读取 Cookie 或访问 115。
- 手动运行时如果没有可用的 115 Cookie 书源，可转去添加书源，或只运行到本地 Torrent 保存。
- 115 Cookie 书源和目标目录选择保存在本机设置中；不保存 Cookie。
- 每日自动工作流默认关闭。移除了会阻止用户启用完整工作流的代码级 P0 开关；启用后按选择的工作模式运行。
- 批次状态按种子展示。结果未知时不盲目重传、不误报成功，并保留本地 Torrent；只有远端任务得到正向核对后，才会按用户的清理设置删除对应 Torrent。
- 已保存种子列表默认只显示最近一项，可展开查看全部。

## 书源列表

- 书源卡片改为紧凑显示：来源图标、名称和当前有效索引中的可阅读漫画数量。
- 本地文件系统与云端书源使用不同图标；移除“离线书目”按钮及“可阅读/需连接”文字。
- 书源详情集中展示漫画数、离线索引数和远程扫描状态。打开详情不触发扫描或网络请求。

## 验证边界

- 版本构建与自动化测试由 GitHub Actions 对本次提交执行。
- 真实 EH 网络收集和所有账号环境下的 115 云端下载状态不由发布构建代替验证；请在对应客户端核对实际任务及文件。
- 当前 P0/P1 研究记录不因 UI 门禁调整而自动改写。
