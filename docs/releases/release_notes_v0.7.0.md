# RCH v0.7.0

本版本新增 SMB、FTP 与 S3 远程书源，完成远程协议、凭据安全与流式阅读的系统性收口，并加入 Android 每日后台任务、平板模式与 115 工作流增强。

## 远程书源

- 新增 **SMB** 书源：纯 Rust SMB2/3，只读访问 Windows 共享或 NAS；支持 Guest、用户名/密码、域账号与旧 UNC 路径写法。
- 新增 **FTP** 书源：明文 FTP，支持 MLSD 列目录、SIZE 取大小，以及 `REST` + `RETR` 随机读取。
- 新增 **S3** 书源：path-style S3 REST + SigV4，支持自定义 endpoint、bucket、region 与前缀；列目录走 ListObjectsV2，大小走 HEAD，阅读走 Range GetObject。
- **SFTP** 增加主机密钥指纹确认与固定：首次连接弹窗展示 SHA-256 指纹，确认后才发送登录凭据；密钥变化时默认拒绝，需要用户显式更新信任。认证方式支持密码或 OpenSSH/PEM 私钥。
- WebDAV / SMB / SFTP / FTP / S3 统一接入远程浏览、封面、打开、进度上报与缓存。

## 流式阅读

- 远程书源的「自动」模式改为真正的流式优先：先按需读取并缓存，失败时才回退整本下载；只有显式选择「优先下载整本」才等待完整下载。
- 大压缩包按 Range 读取，不要求先下载整本；本地缓存目录不会因为「自动」模式而自动增加整本包。

## 凭据与安全

- 新增原生凭据保险箱：Android 使用 Keystore AES-GCM 加密，其他平台使用 `flutter_secure_storage` 保存。
- 远程书源与 WebDAV 同步的密码、Cookie、私钥等敏感字段从明文偏好迁移到保险箱；迁移前先验证可读写，失败则保留旧值并回滚。
- 备份默认不包含凭据；主机指纹与 endpoint 参与信任校验，指纹不匹配时阻止发送凭据。

## 远程扫描与封面

- 修复 S3 特殊文件名读取：签名按服务端原始 key 计算，请求 URL 使用百分号编码，覆盖 `#`、`|`、空格与中文等字符。
- 修复 S3 endpoint 端口与桶根路径处理，修正 `403 Forbidden` 与封面大小读不到的问题。
- 调整远程封面读取预算（按读次数、字节数与时间三重限制），S3 大压缩包封面不再因小读次数过早失败。
- 修复远端书源「0 本漫画」统计：远端扫描没有根目录行时，改为从文件路径推导父路径并校验扫描代数与完成状态；五个协议书源的漫画数恢复为与本地索引一致（同一作品的 `.cbz`/`.zip` 会按作品键去重）。
- 远端目录浏览补齐文件大小，封面缺少来源信息时回退到远程 `file_size`。

## Android、平板与 115

- Android 增加可选的 WorkManager 每日 EH 检查：默认关闭，由系统约束调度，可能延迟；关闭后不保留后台唤醒。
- 增加平板/横屏布局与材质适配，覆盖双页、方向切换和高度受限布局。
- 115 Cookie Web BT 增加每日工作流适配、批次账本与监控增强；云端提交、未知状态与本地 Torrent 清理继续按独立状态处理，不盲目重试或误删。

## 验证边界

- 本轮在本地 OpenList 4.2.4 上实测 SMB、SFTP、WebDAV、FTP、S3 的只读列目录与多本漫画打开；S3 封面可用 240/240，五个远端书源各显示 239 本可阅读漫画。
- 测试环境为 `http://127.0.0.1` 的本地服务，未覆盖公网高延迟、复杂 NAT、企业域控与各云厂商 S3 差异。
- Android 每日后台与平板模式由自动化测试和构建覆盖，本轮未做真机 GUI 验收；115 未做真实云端写入验收。
- 发布前以 GitHub Actions 的 `ci.yml` 全绿为准；真实账号、网络与设备环境仍以客户端实际行为为准。
