# RCH 应用配色与字体设置设计规格

**状态：待用户审阅。规格确认前不开始实现。**

## 背景

RCH 目前只有白天和夜间两种全局外观。它们由 `MaterialApp` 提供，但部分界面仍使用固定的黑、白、灰色，因此仅新增主题入口还不足以让整款应用统一换色。字体也没有单独选项。

## 目标体验

用户可以分别选择亮度、配色和应用字体。选择立即生效并保存在本机，手机与电脑端共用同一套选项。配色预设简洁、易辨认，普通文字在各背景上保持清晰。漫画图片及阅读画布继续由阅读器自己的设置控制。

### 亮度与配色

保留现有「白天 / 夜间」亮度选择，并增加四种固定配色：

| 配色 | 设计方向 | 夜间表现 |
| --- | --- | --- |
| 经典 | 保留当前 RCH 的 Material 外观，作为默认项 | 延续现有深色外观 |
| 海雾 | 固定强调色 `#3A7773`，搭配清爽中性色 | 深蓝绿强调色、深色表面 |
| 暖纸 | 固定强调色 `#876044`，搭配米色层次 | 暖灰棕色表面，保持文字清晰 |
| 墨夜 | 固定石板强调色 `#617187` | OLED 友好的 `#000000`/近黑表面；白天使用中性浅色表面 |

亮度和配色互相独立：例如选择「海雾」后仍可切换白天或夜间。四套配色使用应用内固定的 Material 3 语义色值，不跟随系统动态取色。设置中展示小型颜色预览，并随屏幕宽度换行，避免手机上横向挤压。

文字和背景按语义色角色配对。普通字号文字对比度目标为至少 4.5:1；大字号文字及图形控件满足相应对比度要求。错误、警告、成功等状态颜色继续表达原来的状态，但需选取当前亮度下可辨认的色阶。Material 3 的 `on*` 色角色提供基本配对，仍要单独核对普通文字的 WCAG 对比度。[Material 3 色彩角色](https://m3.material.io/styles/color/the-color-system)、[WCAG 文字对比度要求](https://www.w3.org/WAI/WCAG21/Understanding/contrast-minimum)

### 应用字体

增加两个应用界面字体选项：

- **系统默认**：使用当前平台默认字体，默认选择。
- **系统衬线**：使用平台提供的通用 serif 字体族。

首版不打包字体文件、不联网下载字体。不同操作系统及语言回退可能让衬线字体外观略有差异；这是采用系统字体的预期行为。Android 提供平台默认及 serif 等字体族供应用使用。[Android Typeface 字体族](https://developer.android.com/reference/android/graphics/Typeface)

字体只改变 RCH 的界面文字，不会影响漫画图片中的文字。Flutter 可通过全局 `ThemeData`/文字主题应用字体，也支持字体资源打包；首版选择平台字体，避免额外安装包体积及 CJK 字形覆盖问题。[Flutter 字体设置](https://docs.flutter.dev/cookbook/design/fonts)

### 阅读器画布

应用配色作用于工具栏、菜单、进度信息及其他界面控件。漫画页面区域的底色继续沿用独立阅读器设置，不因切换全局配色而意外改变。其他阅读器也把画布背景作为独立选项，例如 Mihon 提供自动、黑、灰、白背景选择。[Mihon 阅读设置](https://mihon.app/docs/guides/reader-settings)

## 设置入口与适配

在现有「外观与布局」设置分组中，分别展示亮度、配色、字体。配色使用带预览的固定选项，字体使用清楚标注的紧凑选择器。各项在窄屏换行，在宽屏保持舒适间距；手机和桌面使用同一配置。

## 数据与兼容

将配色与字体作为应用设置保存，和现有亮度字段分开。升级前的设置没有这两个字段时，默认进入「经典 + 系统默认」；保留现有夜间模式默认值。无效或未知的设置值安全回退到对应默认值。它们是界面偏好，不新增到漫画元数据或阅读进度同步中。

## 全局适用范围

主题必须覆盖所有由 RCH `MaterialApp` 管理的界面，包括书架、最近阅读、统计、标签、书源、设置以及阅读器控件。为此，需要把通用文字、背景、边框和选择状态从固定灰/黑/白值迁移到语义主题角色。二维码图形、封面图片叠层、状态提示及阅读画布等有明确固定语义或渲染要求的颜色可以保留。

## 验收标准

- 用户可独立切换白天/夜间、四种配色和两种字体，修改后即时生效并在重启后恢复。
- 旧版设置兼容，默认仍是夜间 + 经典 + 系统默认。
- 所有应用页面和阅读器界面控件都跟随所选配色及字体；漫画图片本身不受影响。
- 所有配色/亮度组合中普通文字达到至少 4.5:1 对比度；墨夜在夜间使用近黑表面且文字清晰。
- 通用 UI 颜色遵循主题语义角色；状态色仍然可区分；阅读画布保持独立。
- 设置控件在手机和桌面尺寸下都不发生裁切或拥挤。

## 暂不包含

自定义取色、壁纸、系统动态配色、下载字体或打包大型中文字体、改变阅读画布偏好、漫画格识别。
